The post-launch offer reel, on the user's own voice (`t1.mp3`). The three mistakes are each answered by a real
platform screen: the position tool with risk-based size, the economic calendar on the chart, and the replay plus
analytics on the sample account. The 20% offer is for a user's first purchase only.

**The discount code: FIRST20.** The video never shows the code (it says «کد تخفیف توی کپشن»), so it can change
without re-rendering. The platform has no codes built in, so create it before posting:

1. Admin panel → «کدهای تخفیف» (`/admin/discounts`) → new code.
2. Code `FIRST20`, «درصد تخفیف» 20, tick «فقط اولین خرید».
3. Set «سقف استفاده» and «تاریخ انقضا» as you like (for example 1,000 uses, one month).

The code is checked without regard to case, so `first20` works too. To use another code, change it in the caption
and the pinned comment only.
